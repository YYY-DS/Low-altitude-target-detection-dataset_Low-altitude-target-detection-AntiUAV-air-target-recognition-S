# 低空空中目标检测数据集  | 低空目标检测 反无人机 空中目标识别 小目标检测 多类别检测

## 数据集概述

本数据集面向**低空空域感知、反无人机（Anti-UAV）与空中小目标检测**任务设计，集成了无人机、鸟类、飞机与直升机等典型空中目标图像。数据涵盖天空、城市、山地、森林、海岸、远距离小目标、多目标干扰与复杂背景等多种场景，包含普通图像样本与可见光视频抽帧样本，适用于可见光图像/视频帧中的无人机检测、空中目标分类检测、小目标检测与反无人机算法训练和评测。

## 数据三要素解析

**类别与场景覆盖**
*   数据集定义 **4** 类低空典型目标：**飞机（Airplane）**、**鸟类（Bird）**、**无人机（Drone）**、**直升机（Helicopter）**，覆盖了低空空域主要的人造飞行器与生物目标。
*   场景极其丰富，包括 **纯天空、城市、山地、森林、海岸** 等背景，并包含 **远距离小目标、多目标干扰、复杂背景** 等挑战性样本，有助于提升模型在真实世界中的泛化能力。
*   数据来源多样，包含普通图像与可见光视频抽帧样本，兼顾了静态与动态场景下的目标形态。

**数据规模与标注**
*   图像总量约 **13400** 张，规模充足，能支撑高可靠性多类别空中目标检测模型的训练。
*   数据已按 **训练集（9500张）**、**验证集（2000张）**、**测试集（1800张）** 完成标准化划分，便于模型开发与独立评估。

## 知识普及：低空多类别目标检测的挑战

*   **小目标检测**：空中目标（尤其是远距离的无人机和鸟类）在图像中像素占比极小。本数据集专门包含了大量小目标样本，训练时可采用高分辨率输入（如1280×1280）、增加小目标检测头或使用专门的特征融合网络来提升召回率。
*   **类间相似性**：远距离时，小型无人机与鸟类的形状、大小可能相近，造成混淆。模型需依赖运动模式（可通过视频帧）、细节纹理或热红外信息进行辅助区分。本数据集提供的大量样本是训练这类细粒度分类器的基础。
*   **复杂背景干扰**：城市建筑、山体、云层等背景会严重干扰目标检测。数据集的场景多样性有助于模型学习更具判别力的特征，忽略无关背景。
*   **光照与天气变化**：不同时段、天气下的目标表观差异大。数据增强（如色彩抖动、灰度化）和多场景样本覆盖是提升模型鲁棒性的关键。

## 快速开始（代码示例）

使用本数据集的典型流程如下（基于提供的脚本）：

**1. 准备配置文件** (`aerial_target.yaml`)
```yaml
path: ./aerial_target_dataset
train: images/train
val: images/val
test: images/test
nc: 4
names: ['Airplane', 'Bird', 'Drone', 'Helicopter']
```

**2. 安装依赖并训练**
```bash
pip install ultralytics torch opencv-python
```

```python
from ultralytics import YOLO

model = YOLO("yolo11s.pt")
model.train(
    data="aerial_target.yaml",
    epochs=100,
    imgsz=640,
    batch=16,
    device=0,
    augment=True,
    mosaic=1.0,
    project="runs/train",
    name="aerial_target_detect"
)
# 在测试集上评估
metrics = model.val(split="test")
print(f"mAP@50: {metrics.box.map50:.4f}")
```

**3. 单张图像推理**
```python
model = YOLO("runs/train/aerial_target_detect/weights/best.pt")
results = model.predict(source="test_image.jpg", conf=0.25, save=True)
```
